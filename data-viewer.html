🔌 How PostgreSQL is Connected in MallMaze

MallMaze is configured to use PostgreSQL via Supabase or any standard PostgreSQL instance (Render, Neon, AWS RDS, or localhost).

1. Direct Terminal Inspection:
# Test PostgreSQL connection & view sample rows directly: node scripts/test-pg-connection.js node scripts/view-postgres-data.js
2. Connecting PostgreSQL Database:
# Add your PostgreSQL connection URI to backend/.env: DATABASE_URL="postgresql://postgres:[PASSWORD]@[HOST]:5432/postgres" PGSSLMODE="disable" # or require
