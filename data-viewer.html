🔗 Direct API Endpoints

Access these endpoints directly via browser or API client:
/api/autoshelf/stores - All stores with products /api/catalog/all - All products and stores /api/stores/all - Store listings only /api/db/export - Complete database export (requires auth) /api/admin/users - All users (requires admin auth) /api/admin/orders - All orders (requires admin auth) /api/admin/products - All products (requires admin auth)

💾 PostgreSQL Tables

Your PostgreSQL database contains these projection tables:
mm_users - User accounts and profiles mm_stores - Store information and verification status mm_products - Product inventory and pricing mm_orders - Order details and payment status mm_scan_receipts - Scan & Go receipt records mm_stock_events - Stock change history mm_delivery_jobs - Delivery tracking information mm_support_tickets- Customer support requests mm_feedback - User feedback submissions mm_otp_challenges - OTP verification records mm_reservations - Product reservations
